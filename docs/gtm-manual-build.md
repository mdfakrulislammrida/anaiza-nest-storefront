# Build the container by hand (if the import fails)

Generated by `node --no-warnings scripts/build-gtm-container.ts` from the same code as the import files, so it is exactly the same container. Every name starts with `AN - `.
Work in a **new workspace** of the web container `GTM-MS2HWSWF`. Create things in this order: built-in variables, variables, triggers, tags. Names must match **exactly** (copy them), because tags refer to variables by name.

**Before you publish:** the container already holds nine tags (GA4 Configuration Tag, GA4 Page_view Tag, GA4 view_item Tag, GA4 begin_checkout Tag, GA4 purchase Tag, FB page_view Tag, FB ViewContent Tag, FB InitiateCheckout Tag, FB Purchase Tag). They fire on the same events as the tags below, so **pause or delete them** or every one of those events is counted twice. See `docs/tracking-setup-guide.md`, step 3a.

## 0. Built-in variables

Variables > *Configure* (under Built-In Variables) > tick: **Event**, **Page URL**, **Page Hostname**, **Page Path**, **Referrer**.
